Action Learning for Scientific Simulations

Sarah Liaw1, Yuanqi Du2, Yilun Du1
1Harvard University 2Microsoft Research New England
Paper arXiv Code

TLDR: We introduce action learning, which treats the stochastic action of a system as the learning target and recovers it from trajectory samples as a differentiable path space objective, reusable for inference, steering and sampling without retraining.

Abstract

Understanding and controlling how systems evolve is central to science and engineering, where many problems are defined on trajectories rather than individual states. Existing learned methods often predict local dynamics or generate trajectories, while representative path inference, mechanism steering and constrained trajectory optimization require an objective on complete paths. We introduce LEAP (Learned Energy on Action Paths), which treats the stochastic action itself as the learning target and recovers it directly from trajectory samples. LEAP decomposes the unknown action to an evaluable reference process and learns the remaining path space correction from complete trajectories, yielding a differentiable objective on paths. Once learned, the same action can be reused for path ranking, representative path inference, mechanism tilting, constraints and sampling. Across stochastic transition, orbital and molecular systems, LEAP recovers physical drift from terminally selected trajectories, represents a nonadditive action correction induced by a persistent latent regime and reuses a fixed molecular action for completion, basin preferences, angular constraints and temperature transfer.

From Trajectory Samples to Path Inference

Understanding how systems move between states requires reasoning about the trajectories that connect them, whether two molecular conformations are joined by several transition routes through different intermediates or a robot acts through a sequence of decisions. In these settings the object of interest is often the trajectory itself, namely which paths realize a transition, which mechanisms are plausible and which paths remain likely under perturbations or constraints, and answering such questions requires an objective on complete paths. When the dynamics are known, stochastic action functionals such as the Onsager–Machlup functional provide exactly this objective, assigning to every complete trajectory a physical cost that, for a diffusion, accumulates how far each step departs from the drift.

In many applications, however, we do not know the action and instead observe trajectories from simulation or experiment, such as molecular simulation traces, robot trajectories, policy rollouts or logs of a stochastic process. Learned methods typically fit a one step predictor or a trajectory generator to such data, and while these objects are useful, neither directly gives the reusable path objective that downstream trajectory inference needs. We call the task of recovering an evaluable action from trajectory samples action learning, and the central idea of this work is to treat the action itself as the object to learn, so that one learned action can be ranked against, optimized, steered and sampled long after training.

Learning Action Functionals from Trajectory Samples

The Action as a Path Space Correction

For a discretized trajectory \(\Phi = (x_0, \dots, x_N)\) and conditioning variables \(c\), such as endpoints, terminal regions, horizon or diffusion level, LEAP targets the stochastic action \(S^*(\Phi;c) = -\log p_{\mathrm{data}}(\Phi\mid c) + \alpha(c)\), which it learns from trajectory samples alone, without the underlying drift, potential or simulator likelihood, by writing the unknown action against an evaluable reference path measure,

\[ S^*(\Phi;c) \;=\; \underbrace{-\log p_{\mathrm{ref}}(\Phi\mid c)}_{\text{reference action}} \;-\; \underbrace{\log \frac{p_{\mathrm{data}}(\Phi\mid c)}{p_{\mathrm{ref}}(\Phi\mid c)}}_{\text{path space correction } G^*(\Phi;c)} \;+\; \alpha(c), \]

so that learning the action reduces to learning the path space correction \(G^*\). LEAP estimates \(G^*\) with a setwise comparison objective that scores each observed trajectory against \(K\) reference trajectories of the same context, and every population minimizer of this objective equals \(G^* + a(c)\) for every \(K \ge 1\), so the context dependent term cancels from each comparison and training never needs samples from the learned action.

An Exact Dynamical Correction

When the data and reference are Gaussian Markov processes that share a diffusion coefficient, the correction takes an exact dynamical form, which with \(v_k = (x_{k+1} - x_k)/\Delta t\) and \(u_\theta\) parameterizing \(b_{\mathrm{data}} - b_{\mathrm{ref}}\) reads

\[ G_\theta(\Phi;c) \;=\; \sum_{k=0}^{N-1} \Big[\, \underbrace{\tfrac{1}{2D}\, u_\theta(x_k,t_k;c)^{\top}\big(v_k - b_{\mathrm{ref}}(x_k,t_k;c)\big)}_{\text{velocity alignment}} \;-\; \underbrace{\tfrac{1}{4D}\, \lVert u_\theta(x_k,t_k;c)\rVert^2}_{\text{normalization cost}} \,\Big]\, \Delta t \]

and equals the exact path log likelihood ratio when \(b_{\mathrm{data}} = b_{\mathrm{ref}} + u^*\). Selecting data and reference by the same event, such as a terminal region, then only adds a context constant, so the correction still recovers the original drift, while information shared across the whole trajectory, such as a latent variable fixed along the path, is captured by LEAP-Global, which learns the correction from the complete path instead of summing transition terms.

Downstream Trajectory Inference

Because \(S_\theta\) is an action on complete trajectories, the same learned object can be reused after training to rank candidate paths, infer representative trajectories, incorporate mechanism preferences, impose soft constraints and define trajectory distributions. Each new request simply adds a term to the action and changes the inference problem without retraining the model, and the guarantee carries over, since an action within \(\varepsilon\) of the true one up to a constant has minimizers within \(2\varepsilon\) of optimal under the true action.

Nothing in this recipe is specific to physics, since LEAP only needs trajectory samples and a reference whose path density can be evaluated, so it applies equally to molecular simulations, stochastic physical systems, robot trajectories and logged agent rollouts, where a learned action can help analyze and steer behavior in science, robotics and planning.

Recovering Dynamics under Terminal Selection

Trajectories of the double well \(dX_t = b(X_t)\,dt + \sqrt{2D}\,dW_t\) with \(b(x) = x - x^3\) start at \(x_0 = -1\) and are kept only if \(x_T \in [0.9, 1.1]\) at \(T = 3\). Selecting on the final state changes the distribution of every step, so local regression fits the selected process rather than the original drift. LEAP instead compares the selected paths with a Brownian reference selected by the same window, which changes their path log likelihood ratio only by a constant, and reaches drift MSE \((3.2 \pm 2.7) \times 10^{-4}\), against 0.7752 for cubic regression even though its basis contains the exact drift. With the learned potential fixed, it also infers near optimal paths to new endpoints and horizons.

Recovering a Nonadditive Trajectory Action

An unobserved physical property, like an unknown mass, can stay fixed along a trajectory while its effect accumulates over the whole path. When a hidden sign \(z\), drawn once per path, perturbs the solar mass of a 31 body system, the exact correction after marginalizing \(z\) is \(\sum_k m_k + \log\cosh(\sum_k d_k)\), which couples every transition of the path. LEAP-Local, which scores one transition at a time, stays at the constant prediction level (NRMSE 1.0013), whereas LEAP-Global, which sees the complete path and its sensitivity to the solar mass but never \(z\), reaches 0.2280 and recovers the hidden mass perturbation as \(1.02 \times 10^{-4}\) against the true \(1.04 \times 10^{-4}\). The gap persists at 42 bodies with 64,764 coordinates per path, where LEAP-Global reaches 0.1107 while LEAP-Local stays at 1.0015.

Reusing Learned Actions across Conditions and Objectives

Molecular trajectories are often analyzed in a few collective coordinates whose effective dynamics have no closed form, so we learn one action for alanine dipeptide in its backbone angles \((\phi, \psi)\) from reactive C7eq → C7ax trajectories simulated at 600 K. Keeping this action fixed, we complete paths from a few observed states and add basin preferences and angular constraints without retraining, and with the reference of the new temperature, the correction learned at 600 K also scores 500 K paths on par with a model trained at 500 K (AUROC 0.9579 and 0.9403 within each context).

Conclusion

LEAP treats the stochastic action as a reusable learning target for trajectory data, and learning an objective on path space gives a common interface between trajectory data and diverse downstream inference problems. Looking forward, we hope action learning encourages a broader view for trajectory modeling, in science as well as robotics and other sequential domains, by shifting the focus to learning reusable objectives over complete paths.

Limitations

LEAP requires overlap between the reference and trajectory distributions, and its structured correction is exact for Gaussian Markov processes with shared diffusion, while state dependent diffusion requires more likelihood ratio terms. Our alanine experiments also learn an effective action in \((\phi, \psi)\) instead of the full molecular action.
