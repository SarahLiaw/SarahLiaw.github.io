Action Learning for Scientific Simulations

Sarah Liaw1, Yuanqi Du2, Yilun Du1
1Kempner Institute, Harvard University 2Microsoft Research New England
Paper arXiv Code

Abstract

Understanding and controlling how systems evolve is central to science and engineering, where many problems are defined on trajectories rather than individual states. Existing learned methods often predict local dynamics or generate trajectories, while representative path inference, mechanism steering and constrained trajectory optimization require an objective on complete paths. We introduce LEAP (Learned Energy on Action Paths), which treats the stochastic action itself as the learning target and recovers it directly from trajectory samples. LEAP decomposes the unknown action to an evaluable reference process and learns the remaining path space correction from complete trajectories, yielding a differentiable objective on paths. Once learned, the same action can be reused for path ranking, representative path inference, mechanism tilting, constraints and sampling. Across stochastic transition, orbital and molecular systems, LEAP recovers physical drift from terminally selected trajectories, represents a nonadditive action correction induced by a persistent latent regime and reuses a fixed molecular action for completion, basin preferences, angular constraints and temperature transfer.

From Trajectory Samples to Path Inference

Understanding how systems move between states requires reasoning about the trajectories that connect them. In molecular dynamics, two conformations may be connected by several transition routes that visit different intermediate configurations; in robotics, agents act through sequences of decisions. In these settings, the object of interest is often the trajectory itself: which paths realize a transition, which mechanisms are plausible and which paths remain likely under perturbations or constraints.

Trajectory-level questions require objectives on complete paths. When the dynamics are known, stochastic action functionals such as the Onsager–Machlup functional and the Freidlin–Wentzell rate functional provide one. The action is a physical quantity: it assigns a scalar objective to each complete trajectory, and for a diffusion it adds up how far each step departs from the drift.

In many applications, however, we do not know the action. We instead observe trajectories, like molecular simulation traces, robot trajectories, policy rollouts or logs of a stochastic process, and learned methods often fit a one-step predictor or a trajectory generator. Each answers the question it was trained for; asking which route is typical, or what changes under a new preference, then needs a new model or a new search. We call the task of recovering an evaluable action from trajectory samples action learning, and treat the action itself as the learning target, rather than a local predictor or trajectory generator: it is the object those later questions are asked of.

Learning Action Functionals from Trajectory Samples

LEAP requires trajectory samples for each context \(c\), such as endpoints, terminal regions, horizon or diffusion level, but not the underlying drift, potential or simulator likelihood. It anchors the unknown action to a tractable reference process and learns the remaining correction from complete trajectories:

\[ S_\theta(\Phi;c) \;=\; \underbrace{-\log p_{\mathrm{ref}}(\Phi\mid c)}_{\text{reference action}} \;-\; \underbrace{\widetilde G_\theta(\Phi;c)}_{\text{learned correction}} \]

The correction \(G_\theta\) estimates the path log density ratio of data to reference by comparing each observed trajectory with \(K\) reference trajectories of the same context, and \(\widetilde G_\theta\) centers it under the reference. The reference does not have to follow the physics: in the double well it is Brownian motion with the same diffusion and terminal condition. Training only compares observed paths with reference samples, so it never has to sample from the action being learned. In structured settings, the correction recovers changes in the underlying dynamics; more generally, it can capture nonadditive interactions across transitions.

  • The comparison objective recovers the action up to a context constant, for every \(K \ge 1\).
  • The structured correction recovers drift differences at the states and times visited by the process.
  • Action error controls later inference: with action error \(\varepsilon\), an optimized trajectory is within \(2\varepsilon\) of optimal under the true action, and its normalized density changes by at most a factor \(e^{2\varepsilon}\).

Downstream Trajectory Inference

Because \(S_\theta\) is an action on complete trajectories, we can reuse it after training. The same learned object can rank candidate paths, infer representative trajectories, incorporate mechanism preferences, impose soft constraints and define trajectory distributions. A preference or penalty is added to the action, which changes the inference problem without retraining the model.

Beyond scientific simulation. Nothing in LEAP is specific to physics: it needs trajectory samples for each context and a reference whose path density can be evaluated, so the same recipe applies to logged sequential processes such as robot trajectories or agent rollouts. Such methods may help analyze and steer dynamical systems in science, robotics, planning and other sequential domains.

Recovering Dynamics under Terminal Selection

We use the overdamped diffusion \(dX_t = b(X_t)\,dt + \sqrt{2D}\,dW_t\) with \(b(x) = x - x^3\). Trajectories start at \(x_0 = -1\) and are kept when \(x_T \in [0.9, 1.1]\) at \(T = 3\). LEAP compares these selected paths with a Brownian reference conditioned on the same terminal window. When the data and reference use the same condition, conditioning changes their path log likelihood ratio only by a constant, so the learned correction sees the original drift. LEAP achieves drift MSE \((3.2 \pm 2.7) \times 10^{-4}\). Local regression on the same paths fits the one-step dynamics of the selected process instead: cubic regression reaches 0.7752 even though its basis contains the exact drift. With the learned potential fixed, LEAP also infers near optimal paths to a new endpoint: at \(T = 16\), true path cost 0.2506 versus the analytic 0.2500.

Recovering a Nonadditive Trajectory Action

An unobserved physical property can stay fixed during a trajectory, like an unknown mass in orbital dynamics, and its effect accumulates over the full path. In a 31 body orbital system initialized from JPL HORIZONS, we sample \(z \in \{-1, +1\}\) once and change the solar mass to \(m_\odot(1 + z\eta)\). After marginalizing \(z\), the exact correction becomes \(\sum_k m_k + \log\cosh(\sum_k d_k)\), so no additive transition model can represent it. LEAP-Local and Transition NCE stay at the constant prediction level (NRMSE 1.0013 and 1.0008), while LEAP-Global, which sees the complete path and features accumulated from the nominal dynamics but never \(z\), reaches 0.2280 and recovers the hidden mass perturbation as \(1.02 \times 10^{-4}\), compared to the true \(1.04 \times 10^{-4}\). At 42 bodies and 256 transitions, 64,764 coordinates per path, LEAP-Global reaches 0.1107 while LEAP-Local stays at 1.0015.

Reusing Learned Actions across Conditions and Objectives

Molecular trajectories are often analyzed in a few collective coordinates where the effective dynamics are not available in closed form. We use alanine dipeptide in its backbone angles \((\phi, \psi)\), with 613 reactive C7eq → C7ax trajectories from OpenMM Langevin simulations at 600 K, and keep one learned action fixed. From endpoints and three interior states, it completes paths with circular MSE 0.0931, compared to 0.1191 for conditional diffusion and 0.1247 for conditional flow matching; with endpoints only, the conditional generators get a lower error. Trained at 600 K, it reaches within-context AUROC 0.9579 at 500 K, against 0.9403 for direct 500 K training, and it takes basin preferences and angular constraints without retraining.

Conclusion

LEAP treats the stochastic action as a reusable learning target for trajectory data. Learning an objective on path space enables a common interface between trajectory data and diverse downstream inference problems. Looking forward, we hope action learning encourages a broader view for trajectory modeling, in particular, shifting the focus to learning reusable objectives over complete paths.

Limitations. LEAP requires overlap between the reference and trajectory distribution. The structured correction is exact for Gaussian Markov processes with shared diffusion, and state dependent diffusion requires more likelihood ratio terms. Our alanine experiments learn an effective action in \((\phi, \psi)\) instead of the full molecular action.
